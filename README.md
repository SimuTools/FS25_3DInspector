# 3DInspector

**3DInspector** displays useful status information directly in the game world in Farming Simulator 25.

The mod adds an in-world inspector overlay that can show important information about nearby objects, vehicles, productions, and animals without the need to open separate menus.

## Features

- Displays status information directly in the 3D game world
- Shows fill levels of supported objects
- Shows vehicle information
- Shows production data
- Shows animal information
- Quick inspection without opening extra menus
- Overlay can be shown by holding the **ALT key**
- Designed to stay unobtrusive during normal gameplay

## How It Works

Hold the **ALT key** to display available inspector information in the game world.

When the key is held, 3DInspector checks nearby supported objects and shows relevant status information directly above or near them.

This makes it easier to quickly check important details while walking around the farm, working with vehicles, managing productions, or checking animals.

## Displayed Information

Depending on the object type, the inspector can show different kinds of information.

Examples include:

- Fill levels
- Vehicle status information
- Production status and stored materials
- Animal-related information
- Other useful object details

## Controls

```txt
ALT hold
```

Shows the 3D inspector overlay while the key is held.

## Notes

3DInspector is intended as a lightweight quality-of-life mod.

It helps players quickly inspect objects in the world without interrupting gameplay or opening multiple menus.
